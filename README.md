# Expense-Tracker
A simple Python-based Expense Tracker that helps users record daily expenses, view all transactions, calculate total spending, and analyze expenses by category.

**Features**
Add new expenses
Record expense name, category, amount, and date
View all recorded expenses
Calculate total expenses
View category-wise expense summary
Store expenses in a CSV file
Simple menu-driven interface

**Technologies Used**
Python
CSV Module
OS Module
Datetime Module

**How to Run**
**Clone this repository:**
git clone https://github.com/YOUR-USERNAME/expense-tracker.git
Open the project folder.
Run the Python file:
python expense_tracker.py
Menu Options
Add Expense
View All Expenses
View Total Expenses
View Category Summary
Exit
